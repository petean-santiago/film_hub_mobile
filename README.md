# 🎬 FilmHub App

**FilmHub** is a modern Flutter application that lets users explore, discover, and save their favorite movies — all in one elegant and intuitive mobile experience.

Built with **Flutter** and powered by **The Movie Database (TMDB)** API, FilmHub delivers real-time movie data, smooth animations, and a responsive design that works beautifully on both Android and iOS devices.

---

## ✨ Features

- 🎥 **Movie Discovery** — Browse trending, top-rated, and upcoming movies from TMDB.
- 🔍 **Search Functionality** — Quickly find any film by title or keyword.
- 💾 **Favorites System** — Save and manage your favorite movies with Firebase authentication.
- 🎨 **Modern UI** — Clean layouts, dark mode support, and adaptive design for all screen sizes.
- ⚙️ **API Integration** — Built using the `dio` package for efficient REST communication.
- 🔒 **Authentication** — Secure login and registration via Firebase (email & Google Sign-In).
- 🧪 **Testing Ready** — Includes basic unit and widget tests for reliability and scalability.

---

## 🧠 Architecture

FilmHub follows **clean architecture principles**, separating presentation, logic, and data layers for maintainability.
